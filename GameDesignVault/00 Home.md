## Как пользоваться
- **Новая заметка по шаблону:** `Ctrl/Cmd + P` → «Шаблоны: вставить шаблон». Шаблоны лежат в папке `Templates`.
- **Дневник разработки:** `Ctrl/Cmd + P` → «Ежедневные заметки: открыть сегодняшнюю».
- **Статус заметки** (свойство `status`): `idea` → `design` → `in-progress` → `done`.
- **Граф связей:** `Ctrl/Cmd + G` — видно, какие механики связаны с какими системами.
- Пишите ссылки `[[Название]]` даже на ещё несуществующие заметки — Obsidian создаст их по клику.
