# Механики

Список всех механик игры. Каждая механика — отдельная заметка в папке `Механики`, созданная по шаблону **Механика**.

| Механика | Статус | Приоритет | Системы |
|---|---|---|---|
| [[Передвижение]] | idea | must | [[Система здоровья]]? |
| [[Бой]] | idea | must | [[Система здоровья]] |
|  |  |  |  |

**Приоритеты:** `must` — без этого нет игры · `should` — сильно нужно · `could` — если будет время.
