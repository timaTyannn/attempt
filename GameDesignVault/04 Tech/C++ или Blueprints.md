# C++ или Blueprints

## Правило проекта
**Базовый класс на C++ → наследник в Blueprint.** Логика и данные — в C++, настройка и визуал — в Blueprint.

## В C++
- Основные системы ([[Системы]]): здоровье, инвентарь, сохранения
- Всё, что вызывается часто (Tick, много объектов)
- Сетевой код, репликация
- Базовые классы персонажей, оружия, врагов
- То, что нужно ревьюить в Git (Blueprints — бинарные, их diff не прочитать)

## В Blueprints
- Настройка значений (меши, звуки, эффекты, числа)
- Скрипты конкретного уровня
- Раскладка UI (UMG)
- Быстрые прототипы — потом переносим в C++, если механика прижилась

## Полезно знать
- C++ код может писать и ревьюить Claude Code (в том числе в облачной сессии), Blueprints — нет.
- `UFUNCTION(BlueprintCallable)` / `BlueprintImplementableEvent` / `BlueprintNativeEvent` — мосты между C++ и BP.
