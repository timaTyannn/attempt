# Система здоровья

## Задача
Хранить здоровье, принимать урон, сообщать о смерти. Используется в [[Бой]].

## Классы
- `UHealthComponent : UActorComponent` — вешается на игрока и врагов

## API (черновик)
```cpp
UPROPERTY(EditDefaultsOnly, BlueprintReadOnly) float MaxHealth = 100.f;
UPROPERTY(BlueprintReadOnly)                   float CurrentHealth;

UFUNCTION(BlueprintCallable) void ApplyDamage(float Amount, AActor* Instigator);
UFUNCTION(BlueprintCallable) void Heal(float Amount);

DECLARE_DYNAMIC_MULTICAST_DELEGATE_TwoParams(FOnHealthChanged, float, NewHealth, float, Delta);
UPROPERTY(BlueprintAssignable) FOnHealthChanged OnHealthChanged;

DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FOnDeath, AActor*, Killer);
UPROPERTY(BlueprintAssignable) FOnDeath OnDeath;
```

## Зависимости
- UI подписывается на `OnHealthChanged` → полоска здоровья в `WBP_HUD`

## Сетевой режим
Нужна репликация? `CurrentHealth` → `ReplicatedUsing=OnRep_Health`

## Тесты / как проверить
- [ ] Урон уменьшает здоровье
- [ ] Здоровье не уходит ниже 0 и выше максимума
- [ ] `OnDeath` вызывается ровно один раз
