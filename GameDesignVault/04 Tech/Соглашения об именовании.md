# Соглашения об именовании

## Ассеты (префиксы)
| Тип | Префикс | Пример |
|---|---|---|
| Blueprint | `BP_` | `BP_PlayerCharacter` |
| Widget Blueprint | `WBP_` | `WBP_HUD` |
| Animation Blueprint | `ABP_` | `ABP_Hero` |
| Animation Montage | `AM_` | `AM_Attack_Light` |
| Animation Sequence | `A_` | `A_Hero_Run` |
| Blend Space | `BS_` | `BS_Hero_Locomotion` |
| Static Mesh | `SM_` | `SM_Crate` |
| Skeletal Mesh | `SK_` | `SK_Hero` |
| Skeleton | `SKEL_` | `SKEL_Hero` |
| Material | `M_` | `M_Rock` |
| Material Instance | `MI_` | `MI_Rock_Wet` |
| Texture | `T_` + суффикс | `T_Rock_D` (diffuse), `_N` (normal), `_ORM` |
| Niagara System | `NS_` | `NS_Explosion` |
| Sound Wave / Cue | `SW_` / `SC_` | `SC_Footstep` |
| Data Asset | `DA_` | `DA_Weapon_Sword` |
| Data Table | `DT_` | `DT_Enemies` |
| Enum / Struct (BP) | `E_` / `F_` | `E_WeaponType` |
| Input Action | `IA_` | `IA_Jump` |
| Input Mapping Context | `IMC_` | `IMC_Default` |
| Map (уровень) | `L_` | `L_Level01` |

## C++ (стандарт Epic)
| Что | Префикс | Пример |
|---|---|---|
| Наследник `AActor` | `A` | `AMyCharacter` |
| Наследник `UObject` / компоненты | `U` | `UHealthComponent` |
| Структура | `F` | `FWeaponStats` |
| Enum | `E` | `EWeaponType` |
| Интерфейс | `I` | `IInteractable` |
| Bool-переменная | `b` | `bIsDead` |
