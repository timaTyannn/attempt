# Структура папок

## Content (ассеты)
```
Content/
├── _Game/                ← всё наше — в одной папке, отдельно от Marketplace-ассетов
│   ├── Core/             ← GameMode, PlayerController, GameInstance (BP-наследники)
│   ├── Characters/
│   │   ├── Hero/
│   │   └── Enemies/
│   ├── Weapons/
│   ├── Environment/
│   ├── Maps/
│   ├── UI/
│   ├── Input/            ← Input Actions и Mapping Contexts
│   ├── Data/             ← Data Assets, Data Tables
│   ├── Materials/
│   ├── VFX/
│   └── Audio/
├── Developers/           ← личные эксперименты, в билд не попадают
└── [Marketplace-паки]    ← как пришли, не трогаем
```

## Source (C++)
```
Source/MyGame/
├── MyGame.Build.cs
├── Public/
│   ├── Core/
│   ├── Characters/
│   ├── Components/
│   ├── Systems/
│   └── UI/
└── Private/              ← зеркально Public
```

## Git
- `Content/**` — через **Git LFS** (`*.uasset`, `*.umap`)
- В `.gitignore`: `Binaries/`, `Intermediate/`, `Saved/`, `DerivedDataCache/`, `.vs/`, `*.sln`
