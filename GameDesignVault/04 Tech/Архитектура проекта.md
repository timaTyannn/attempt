# Архитектура проекта

- **Версия Unreal Engine:** 5.x
- **Язык:** C++ + Blueprints (см. [[C++ или Blueprints]])
- **Имя основного модуля:** `MyGame`
- **Мультиплеер:** да / нет (если да — сразу думаем о репликации!)

## Каркас Gameplay Framework
| Класс Unreal | Наш класс | За что отвечает |
|---|---|---|
| `UGameInstance` | `UMyGameInstance` | Живёт всю игру: настройки, сохранения, переходы между уровнями |
| `AGameModeBase` | `AMyGameMode` | Правила уровня (только на сервере) |
| `AGameStateBase` | `AMyGameState` | Общее состояние матча, видно всем |
| `APlayerController` | `AMyPlayerController` | Ввод, UI, связь игрока с пешкой |
| `APlayerState` | `AMyPlayerState` | Данные игрока, которые переживают смерть пешки |
| `ACharacter` | `AMyCharacter` | Тело игрока в мире |
| `AHUD` / UMG | `WBP_HUD` | Интерфейс |
