# Хемоформ — handoff для нового чата

Проект: дипломная игра «Нексус» (Unreal Engine). Модуль «Хемоформ» — лабораторный стол, на котором
игрок определяет вещество в пробе. Интерфейс — терминал на меше стола, 1920×1080, в игре собирается
в **Rive**. Макеты делаются как HTML-страницы (публикуются артефактами claude.ai) и переносятся в
**Figma** редактируемыми слоями.

Репозиторий: `timatyannn/attempt`, ветка `claude/gifted-darwin-ix7a0t`.
Всё по интерфейсу лежит в `design/chemoform/`, решения и история — в
`GameDesignVault/05 Art & Audio/UI Хемоформ.md`. Общайся по-русски.

## Стиль (обязательно соблюдать)

- **Плоско.** Линии 1 px, без теней. Один акцент `#3dd4c4` — только у выбранного и у того, что можно
  нажать. Тёмные чернила на акценте `#0b201e`.
- **Красный `#e5534b`** — только на экране провала (вердикт, списанная доля, опровергнувшее измерение).
- **Исключение — вкладка «Приборы»:** выбор прибора подсвечивается снизу (градиент) и бирюзовым
  чертежом за краем карточки, карточка «подъезжает». Это есть только там.
- **Токены:** фон `#121212`, карточка `#1b1c1c`, выбранная строка `#1c1e1e`, линии `#262828`/`#333`,
  текст `#ececec`, серый `#8a8a8a`, тусклый `#3f4141`/`#4a4c4c`.
- **Шрифты:** Disket Mono — надписи, цифры, заголовки (только заглавные!); Jost — обычный текст.
  Символы химических элементов (Na, Cl) — Jost, иначе Disket сделает «NA». Не мельче 20 px при 1920.
- **Шапка:** 5 вкладок — Образец · Приборы · База данных · Журнал · Улучшения. Активная — подсветка
  снизу и черта 4 px. **Клавиши Q/E и A/D не рисуем** (решено; геймпад LB/RB — на подумать).
- **Низ:** `1 ЛЕВЫЙ · 2 ЦЕНТР · 3 ПРАВЫЙ · 4 ГОЛОГРАММА` (мониторы). ESC не рисуется.
- Пользователь любит: **три варианта** на новый экран, потом выбирает/комбинирует; короткие ясные
  тексты на экране, без служебных пометок для дизайнера.

### Образец (готово)
Подвкладки **ОБЗОР · ОТЧЁТ · + НОВЫЙ ОБРАЗЕЦ** («+ новый образец» — действие, отделено чертой;
пока дело открыто, «Отчёт» и «Новый образец» серые). Один шаблон на все экраны:
слева текст (проба/ответ), в центре **мерная пробирка**, справа список.
- **Механика пробы:** пробирка показывает остаток в %, каждый прибор отпивает долю, повтор стоит
  столько же. Черновые цены: масс-спектрометр 15 %, хроматограф 20 %, ИК 10 %, УФ 10 %, pH-метр 5 %,
  ЯМР 25 %, реактор 30 %; голограмма и центрифуга — 0. 100 % = 10 мл.
- **Обзор:** справа список расхода — строка высотой с долю (6 px на 1 %), выноски от делений
  пробирки; под уровнем «Осталось 4,5 мл» и «Кончится — новую пробу привезёт дрон».
- **Отчёт · определено:** слева «ВЕЩЕСТВО ОПРЕДЕЛЕНО», CO₂, «почему вода кислит», проба/структура,
  «НОВЫЙ ОБРАЗЕЦ →»; под уровнем награда +2 (вещество + экономия ≥ 40 %) и остаток → хранилище.
- **Отчёт · провал:** исходов только два, **попытка одна**. Остаток списывается красной долей,
  пробирка 0 %, ответ игрока зачёркнут красным, показан верный, строка ИК (опровергала) — красная.
- **Новый образец:** выбранная проба КР-02 слева, полная пробирка, список хранилища (новая / в пути).
- Сквозной пример: КР-01, ледник «Северный», CO₂ — масса 44, осколок 12, ИК 2349 и 667, O=C=O.

### База данных (выбрано, перенести в Figma)
«Учебник с поиском». Подвкладки **ПРИБОРЫ · ТАБЛИЦА · СПРАВОЧНИК · ВЕЩЕСТВА**.
Слева: поле поиска по всей базе, оглавление раздела, параграфы статьи. Справа: страница учебника
(заголовок, абзац, плашки, рисунок, шаги), внизу листание. Четыре экрана:
1. Прибор · §3 «Как пользоваться» (рис. 3.1 — принципиальная схема ИК, шаги 1–5).
2. Прибор · §2 «Как устроен» — изометрический чертёж ИК с 5 выносками (из варианта «Схема»).
3. Поиск «2349» → слева результаты по подвкладкам, справа «Таблица ИК-зон» с подсвеченной строкой.
4. Таблица Менделеева (вариант «Учебник»): таблица слева, карточка элемента справа, легенда.
Статья прибора всегда из 5 параграфов: что показывает, как устроен, как пользоваться, как читать
результат, ошибки. Элементы из проб подсвечены.

### Приборы
Избранные направления: постер, аккордеон-полосы, инверсия, бегущая строка; чертежи приборов 1 px
(ISO и 2D). Эталон выбора — кадр пользователя в Figma `321:1081` (на странице `0:1`), его не трогать.
Моушн полос для Rive — `rive-motion-strips.md`.

## Сборка и перенос

- **Шрифт Disket** в git нет. `build.py` ждёт `design/chemoform/fonts/DISKET-MONO-{REGULAR,BOLD}.TTF`.
  Если файлов нет — base64 шрифта можно вытащить из любого опубликованного артефакта
  (`@font-face … base64,…`) и подставить вместо `__DISKET_REG__` / `__DISKET_BOLD__`.
- Исходники в `src/*.html` — уже собранные страницы с плейсхолдерами шрифтов; правим их напрямую.
- Скриншоты экранов: Playwright + Chromium (`NODE_PATH=$(npm root -g) node script.js`), каждый
  экран — `.comp > .scr` 1920×1080, масштабируется через `transform`.
- **Перенос в Figma экранов «Образца»** — `figma/sample/`:
  ```
  node figma/sample/card-extract.js build/sample.html figma/sample/x-spec.json <индекс .comp>
  python3 figma/sample/gen.py frame PAGE HDR FTR figma/sample/x-spec.json "Имя кадра" <x> figma/sample/out.js
  ```
  `out.js` выполняется через `use_figma` (держать скрипт < 45 000 символов). Скрипт понимает
  пробирку (уровень из `data-level`), строки расхода, красные строки, пустую пробирку и любые
  дополнительные группы. Перед извлечением Jost нужно встроить локально, иначе замеры текста съедут.
- Для «Базы данных» скрипт нужно расширить (левая колонка, таблица Менделеева, чертёж с выносками)
  или собрать по образцу `card-extract.js` + `frame.tpl.js`.
- Rive: слушатели только в корневом артборде `CF_MainTable_ScreenBriefing_Main`, клик пишет `nav`
  в VM, `pulse` каждый тик; пробирка — компонент с number `level` 0–100.

## Открытые вопросы

- Показывать ли верный ответ при провале (сейчас показан).
- Окно подтверждения на голограмме: «Отправить отчёт? Попытка одна».
- Порог экономии 40 % и цены приборов — баланс.
- Показывать цену пробы на полосах «Приборов» (−15 %).
- Финальная композиция «Приборов»; 2D или ISO чертежи; 1 px на меше (может 1,5 px).
- Клавиши для геймпада (LB/RB, LT/RT только при геймпаде?).
