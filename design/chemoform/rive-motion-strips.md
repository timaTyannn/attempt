# Моушн полос-аккордеона — ТЗ для Rive

Эталон — вариант А на странице «Обзор» (`src/overview.html`): пять полос, выбранная раскрыта.
Тот же приём — у выбора приборов. Значения сняты с CSS макета.

## Промпт

> Сделай в Rive горизонтальный ряд из N вертикальных полос (карточек) высотой 832 px.
> Свёрнутая полоса шириной 132 px, зазор 10 px, раскрыта всегда ровно одна — она забирает
> остаток ширины ряда. При наведении курсора или смене фокуса с геймпада раскрытая полоса
> плавно сворачивается, а новая так же плавно раскрывается: обе за 420 мс, кривая
> cubic-bezier(0.2, 0.7, 0.2, 1), поэтому общая ширина ряда не дрожит.
> В свёрнутой полосе сверху иконка 34 px, по центру название, повёрнутое на 90° и читаемое
> снизу вверх, внизу точка «новое» 12 px. В раскрытой: надзаголовок, название 58 px,
> описание, черта 146 px, подпись и значение. Свёрнутое содержимое гаснет за 200 мс, раскрытое
> проявляется за 300 мс с задержкой 80 мс. Фон полосы светлеет с #1B1C1C до #222424, снизу
> проявляется бирюзовая подсветка (градиент #3DD4C4 30% → 0 на 72% высоты) и рамка 3 px
> (#3DD4C4 → прозрачный к верху), за 320 мс. Чертёж прибора линией 1 px торчит за правый
> нижний край полосы и обрезается её маской: проявляется за 240 мс с задержкой 60 мс,
> перекрашивается из #4A4D4D в #3DD4C4 за 320 мс, слегка «подъезжает к игроку» — масштаб
> 1 → 1.05 и сдвиг (−8, −6) за 450 мс. Неизученная полоса темнее (#141515), название на 20%
> непрозрачности. Всё прерываемо: быстрый проход курсором по ряду не должен оставлять
> полос в промежуточном виде.

## Геометрия

| | значение |
|---|---|
| Ряд | ширина W, высота 832; в «Обзоре» W = 1140 (x 680…1820, y 128) |
| Свёрнутая полоса | 132 × 832 |
| Зазор | 10 |
| Раскрытая полоса | W − (N − 1) × 142; при W = 1140 и N = 5 это 572 |
| Чертёж | 620 × 500, правый край −96, нижний −84 от краёв полосы, обрезан полосой |
| Раскрытое содержимое | отступы 44, ширина 580 (у узкой полосы обрезается — так и задумано) |

Позиция полосы i при раскрытой k: `x = i × 142`, если i ≤ k, иначе `x = i × 142 + (open − 132)`.
Все x и ширины — целые пиксели, иначе линии 1 px поплывут на меше.

## Тайминги

Кривая для всего: Cubic, ручки (0.2, 0.7) и (0.2, 1). В Rive — интерполяция Cubic с этими точками.

| Что | Свёрнута → раскрыта | Задержка | Длительность |
|---|---|---|---|
| Ширина полосы | 132 → open | 0 | 420 мс |
| Фон | #1B1C1C → #222424 | 0 | 320 мс |
| Подсветка снизу (opacity) | 0 → 1 | 0 | 320 мс |
| Рамка 3 px (opacity) | 0 → 1 | 0 | 320 мс |
| Свёрнутое: иконка, название, точка | 1 → 0 | 0 | 200 мс |
| Раскрытое: текст и значения | 0 → 1 | 80 мс | 300 мс |
| Чертёж (opacity) | 0 → 1 | 60 мс | 240 мс |
| Чертёж (цвет линии) | #4A4D4D → #3DD4C4 | 0 | 320 мс |
| Чертёж (заливка граней) | #1B1C1C → #222424 | 0 | 320 мс |
| Чертёж (масштаб, сдвиг) | 1 → 1.05, (0,0) → (−8,−6) | 0 | 450 мс |
| Название | #BDBDBD → #FFFFFF | 0 | 320 мс |
| Надзаголовок | #8A8A8A → #3DD4C4 | 0 | 320 мс |
| Описание | #8A8A8A → #D0D0D0 | 0 | 320 мс |

Сворачивание — те же значения в обратную сторону, но раскрытый текст гаснет быстрее:
150 мс без задержки, а свёрнутое содержимое проявляется с 120 мс. Иначе на сжимающейся
полосе на миг видны оба набора текста.

«Подъезд к игроку» в ряду делает только чертёж. Сама полоса не масштабируется и не
поднимается — она залезла бы в зазоры, а движение уже есть у соседей.

## Состояния полосы

| Состояние | Вид |
|---|---|
| Свёрнута | фон #1B1C1C, чертёж скрыт, иконка и название серые |
| Раскрыта | всё из таблицы выше |
| Неизучена | фон #141515, название и иконка на 20%, точки нет |
| Новое | точка #3DD4C4 внизу свёрнутой полосы |

Решить: попадает ли фокус на неизученные полосы. Если нет — их машине состояний не
нужно «Раскрыта», фокус перескакивает их.

## Устройство в Rive

- **Корневой артборд** держит геометрию и все слушатели — правило проекта: listeners
  только в `CF_MainTable_ScreenBriefing_Main`.
  - Слой машины состояний «Фокус»: состояния `Focus_0 … Focus_N-1`, в каждом —
    поза из одного ключа: x и ширина всех полос и их зон нажатия.
  - Переход в `Focus_i` из любого состояния по `focus == i`, длительность 420 мс,
    интерполяция Cubic (0.2, 0.7, 0.2, 1), Exit Time выключен. Rive смешивает текущую
    позу с целевой, поэтому смена фокуса посреди анимации не дёргается.
  - Зоны нажатия — прозрачные прямоугольники поверх полос, двигаются в тех же позах.
    Pointer Enter → `focus = i`; Pointer Down → `nav = i`.
  - Вариант проще: Row Layout с зазором 10, ширина полос ключуется в тех же позах,
    соседи сдвигаются сами. Зоны нажатия тогда кладутся в такой же ряд.
- **Полоса** — вложенный артборд `CF_Cmp_Strip`, у него своя машина состояний:
  - вход bool `isOpen` (привязан к VM: `focus == index`), bool `isExplored`, bool `isNew`;
  - состояния `Collapsed` и `Open`, переходы по `isOpen`, тайминги из таблицы;
  - текст из VM: `eyebrow`, `title`, `desc`, `keyLabel`, `keyValue`; чертёж — вложенный
    артборд или переключатель по `artIndex`.
  - Подсветка и рамка — две фигуры с линейным градиентом и своей opacity; рамка — обводка
    3 px с градиентом, внутренняя (Inner).
  - Маска полосы (Clip) обрезает чертёж и раскрытый текст.
- **VM корня:** number `focus`, number `nav`, `pulse` — как в остальных экранах
  (пишется каждый тик), bool `reduceMotion`.
- **Геймпад и клавиатура:** игра пишет `focus` (←/→ или A/D, D-pad), Enter или A —
  `nav = focus`.
- **reduceMotion:** все переходы с длительностью 0, чертёж без масштаба.

## Проверка

1. Быстро провести курсор по всем полосам туда и обратно — ширина ряда не меняется ни
   в одном кадре, никакая полоса не остаётся полураскрытой.
2. Остановиться на полосе на 100 мс и уйти — она сворачивается из текущей точки, без скачка.
3. Линии чертежа 1 px не мылятся на меше. Если мылятся — выключить у обводки
   «Transform affects stroke» или убрать масштаб 1.05 и оставить только сдвиг.
4. Неизученная полоса не светится и при наведении.
